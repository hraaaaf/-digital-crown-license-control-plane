# Digital Crown License Control Plane

Private control plane for Digital Crown production license signing.

## Security

- Private signing keys must never be committed to this repository.
- Production secrets must never appear in logs or artifacts.
- Only public trust keys may be exported to the Digital Crown client.
- Production signing operations must be explicitly authorized.
- Existing production signing material must never be silently overwritten; rotation is a separate reviewed procedure.

## Preferred provisioning: GitHub-only

The production Ed25519 keypair is generated by the manual **Bootstrap production signing key** workflow.

The workflow:

1. requires the exact confirmation `PROVISION`;
2. refuses to run if production signing material already exists;
3. generates and self-tests an Ed25519 keypair in runner memory;
4. encrypts the private key directly to GitHub Actions Secrets using the repository Actions-secrets public key;
5. stores only the non-secret key id and public key as repository variables;
6. verifies GitHub metadata/readback;
7. deletes the one-time bootstrap token secret;
8. never prints or uploads the private signing key.

### One-time bootstrap authorization

Create a fine-grained personal access token restricted to this repository with only:

- Repository **Secrets: Read and write**
- Repository **Variables: Read and write**

Use the shortest practical expiration. Store that token temporarily as the repository Actions secret:

- `DC_CONTROL_PLANE_BOOTSTRAP_TOKEN`

Then run **Actions > Bootstrap production signing key > Run workflow**, enter `PROVISION`, and run it once.

On success the repository contains:

Secret:

- `DIGITALCROWN_LICENSE_SIGNING_PRIVATE_KEY_B64URL`

Variables:

- `DIGITALCROWN_LICENSE_SIGNING_KEY_ID`
- `DIGITALCROWN_LICENSE_SIGNING_PUBLIC_KEY_B64URL`

The bootstrap workflow deletes `DC_CONTROL_PLANE_BOOTSTRAP_TOKEN` after successful readback.

After provisioning, run **Validate production license signing** to independently load the stored secret and verify the private/public Ed25519 match with an in-memory sign/verify test.

## Local fallback

`scripts/generate_ed25519.py` remains available for a trusted offline/control-plane machine. It refuses to write private material inside this repository and never prints the private key value.
